# Programming

Unless you've been living under a rock, you are probably aware that programming with Python and use of AI tools is becoming increasingly commonplace in science and engineering fields. In my opinion, working with these tools for your engineering work is one of the most useful skills you can acquire while you are still a student.

I've been trying to decide how to integrate programming into the course without letting it distract from the more fundamental and theoretical topics we need to cover. I've also had to get up to speed with the platforms and tools you (as students) have available to you at the university. At UC Berkeley we all have access to Google Gemini, which can be used interactively as a chat interface within a Colab notebook (Google's version of a Jupyter notebook). It is easy to use and very capable of solving many of the problems we cover in class. A simple set of instructions is provided on the [Google Colab page](./programming/colab) of this workbook.
